# Bellogue — 설치 & 디버깅 가이드 (최소 버전)

로어북 조건은 잠시 빼고, **일단 마법봉 메뉴에 버튼이 뜨는지부터** 확인하는 버전이에요.

## 설치 방법

1. GitHub 저장소에 `manifest.json`, `index.js`, `style.css` 3개 파일 업로드
2. SillyTavern → 확장프로그램(퍼즐 조각) 아이콘 → **Install extension** → 저장소 URL 입력
3. 새로고침 → 마법봉(⚡) 메뉴 열어서 "Bellogue" 보이는지 확인

## 저번에 안 떴던 것, 디버깅 순서

**1. 브라우저 콘솔부터 확인해주세요 (제일 중요해요)**
- PC: F12 → Console 탭
- 안드로이드 브라우저: 주소창에 `about:inspect` 치거나, 크롬이면 PC에 연결해서 원격 디버깅
- 빨간 글씨 에러가 있으면, 특히 "bellogue"라는 단어가 들어간 줄이 있으면 스크린샷 부탁드려요. 지난번엔 아마 로어북 관련 코드(`SillyTavern.getContext()`)에서 에러가 나서 스크립트 전체가 멈췄을 가능성이 커요. 이번 버전엔 그 코드를 통째로 뺐어요.

**2. 확장프로그램 관리 탭에 아예 안 뜨는 경우**
이건 SillyTavern이 폴더 자체를 못 찾는 경우예요. 확인해주세요:
- 설치 후 실제 파일 위치가 `SillyTavern/public/scripts/extensions/third-party/[저장소이름]/manifest.json` 이렇게 되어 있는지 (그 안에 또 폴더가 한 겹 더 있으면 안 돼요)
- `manifest.json` 파일이 정확히 그 이름인지 (오타 없이)

**3. 그래도 안 되면**
- 확장프로그램 관리 탭 화면 스크린샷
- 설치 시도했을 때 떴던 메시지(성공/실패 문구) 스크린샷
- 브라우저 콘솔 스크린샷

이 세 개만 있으면 바로 원인 찾을 수 있을 것 같아요!

## 지금 버전에 들어있는 것

- 마법봉 메뉴에 "Bellogue" 버튼 (조건 없이 항상 뜸)
- 버튼 누르면 모달 열림 (일기/방명록 탭, 데스크탑 2페이지 / 모바일 1페이지+탭)
- 로어북 감지 코드는 **완전히 제거** — 이거 뜨는 거 확인되면 다시 붙일게요
